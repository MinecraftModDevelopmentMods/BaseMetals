Base Metals `3.1.1.120061` targets Minecraft 1.20.6, Forge 50.2.0 and Java 21.
OreSpawn `4.1.0.120061` is the exact build and test dependency. Clients and
servers need OreSpawn `[4.1.0.120061,5.0.0)`.

The pinned CurseForge artifact is project 245586, file 9183384:
`curse.maven:mmd-orespawn-245586:9183384`.
Its SHA-256 is
`FAA7107B9FB84E2C62ED847CAFD880AA3C4238A37799BAD955EA9602A944AA26`.

Release artifacts use Maven coordinate
`zone.moddev.mc.basemetals:BaseMetals:3.1.1.120061`.

The provider remains schema 3, revision 1. OreSpawn 4.1 is needed for the
configuration-screen API; the provider's eleven rule IDs and 1.18 distributions
have not changed.

Base Metals `3.1.0.118021` targets Minecraft 1.18.2, Forge 40.3.0 and Java 17.
OreSpawn `4.1.0.118021` is the exact build and test dependency. Clients and
servers need OreSpawn `[4.1.0.118021,5.0.0)`.

The pinned CurseForge artifact is project 245586, file 9097992:
`curse.maven:mmd-orespawn-245586:9097992`.
Its SHA-256 is
`BD8D84A96DAFB7668E95D61B9D72C62AEF3440675473E41244C182C64653356F`.

Release artifacts use Maven coordinate
`zone.moddev.mc.basemetals:BaseMetals:3.1.0.118021`.

The provider remains schema 3, revision 1. OreSpawn 4.1 is needed for the
configuration-screen API; the provider's eleven rule IDs and 1.18 distributions
have not changed.

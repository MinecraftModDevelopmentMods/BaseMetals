# OreSpawn 4.1.0 schemas

These public schemas match OreSpawn 4.1.0.120061. The Base Metals provider
still uses schema 3 and revision 1; its ore rules have not changed.

The build validates the provider against this snapshot. OreSpawn 4.1 is also
needed for the Base Metals configuration button in its world-creation screen.

Source: [OreSpawn 4.1.0.120061](https://github.com/MinecraftModDevelopmentMods/OreSpawn/releases/tag/4.1.0.120061).

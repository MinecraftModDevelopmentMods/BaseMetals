2.5.1.111021 for Minecraft 1.11.2

This update brings the newer Base Metals features to 1.11.2. It requires
Forge 13.20.1.2588 or later and MMD OreSpawn 4.1.6.111021 or a compatible
newer 4.x version for 1.11.2.

- Open the Base Metals settings from the Mods list or the cog in OreSpawn.
- High Fantasy keeps the usual recipes and is the default. Low Fantasy limits
  what you can make without removing anything from your world or changing
  where ores spawn. Use the same setting on the client and server.
- Molten metal now burns even in shallow flows. Mercury still causes nausea.
- OreSpawn handles all eleven Base Metals ore rules. It keeps existing
  overrides when importing older settings and avoids adding a second set of
  veins when you move an imported OreSpawn 1 world to a new instance.
- JEI shows Crack Hammer recipes, Base Metals rods use the 1.11.2 fishing
  hook, and the material API still uses Minecraft's iron nugget.
- The Java packages and Maven group move to zone.moddev.mc.basemetals.
  Existing add-ons can still use the old class names. Saved block and item
  IDs and config names stay the same.
- The build now uses ForgeGradle 7 and Gradle 9.6.1. Minecraft still runs on
  Java 8. Eclipse launches handle paths with spaces, and CI checks old-world
  upgrades as well as the build and release files.
